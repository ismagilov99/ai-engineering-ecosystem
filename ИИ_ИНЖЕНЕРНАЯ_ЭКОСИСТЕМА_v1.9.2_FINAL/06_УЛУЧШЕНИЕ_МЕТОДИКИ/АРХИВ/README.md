# Архив исходных заметок по улучшению Методики

Этот каталог предназначен для неизменённых исходных материалов, которые объясняют происхождение предложений по развитию Методики.

Файл `ЗАМЕТКИ_ПО_УЛУЧШЕНИЮ_v1.0.1_ИСХОДНИК.md` перенесён из предоставленного комплекта v1.7.0. Он сохраняется как исходный документ и не должен редактироваться, сокращаться, переименовываться или заменяться новой редакцией.

Новые наблюдения, предложения, решения и подготовленные редакции записываются отдельно в `../ЗАМЕТКИ.md` и, при необходимости, в целевые разделы Методики после согласования владельца.

Архив не является списком действующих правил. Если положение из исходной заметки позднее утверждено и внесено в Методику, источником текущего правила становится соответствующая активная редакция Методики, а этот файл остаётся свидетельством происхождения.
