# Инсайты

Здесь хранятся принятые записи `INSIGHT` — ограниченные обобщения, закономерности и выводы, имеющие повторную ценность.

INSIGHT должен содержать ясное утверждение, источники и claims, условия применимости, границы, контрпримеры и способ проверки. Указывай, какие исходные эпизоды независимы, а какие являются пересказами одного источника.

Один эпизод может стать основанием для гипотезы, но не доказывает универсальную закономерность. Не обобщай личное предпочтение или единичную неудачу до глобального правила. Не смешивай `inference` или `hypothesis` с `test_verified`.

Используй `INSIGHT_TEMPLATE.md`. Если insight содержит отвергнутый вариант, фиксируй контекст, причину отказа, evidence, границы применимости и условия пересмотра. Negative Memory не является отдельным типом записи.

Каталог пока остаётся плоским. Темы указываются через `domain` и `tags`; новые тематические подпапки вводятся только при реальном росте записей и после обновления правил навигации.
