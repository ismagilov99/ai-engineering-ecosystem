# ПРОЕКТИРОВАНИЕ API

Процедуры проектирования API, контрактов, схем запросов/ответов, версионирования, совместимости и обратного развития интерфейсов.

Сюда помещаются только принятые записи `SKILL`, оформленные по `../ШАБЛОНЫ/SKILL_TEMPLATE.md` и прошедшие Outcome Gate. Перед активным размещением требуется DRY RUN Sorter и явное решение владельца. Не помещай сюда EXPERIENCE-эпизоды, INSIGHT или непроверенные черновики.
