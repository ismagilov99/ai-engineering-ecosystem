# Навыки

Здесь хранятся принятые в активную БЗ записи `SKILL`. Каждая запись описывает воспроизводимую процедуру, прошедшую Outcome Gate. Простая идея, удачный единичный ответ или неподтверждённый совет не являются Skill.

## Как выбирать категорию

Выбери одну основную инженерную область по назначению навыка. Дополнительные темы укажи в `tags`; не копируй файл в несколько папок.

Подготовлены тематические каталоги:

- `АУДИТ_БЕЗОПАСНОСТИ/` — security review, threat modeling, проверка контроля доступа, анализ риска и безопасные проверки;
- `ПРОЕКТИРОВАНИЕ_API/` — проектирование API и интерфейсов, контракты, совместимость, версионирование;
- `РАБОТА_С_БАЗАМИ_ДАННЫХ/` — проектирование данных, SQL, миграции, целостность и эксплуатация;
- `АРХИТЕКТУРА_И_ПРОЕКТИРОВАНИЕ/` — декомпозиция, архитектурные решения, границы компонентов и системное проектирование;
- `РАЗРАБОТКА_И_КОД/` — написание, рефакторинг, отладка и сопровождение кода;
- `ТЕСТИРОВАНИЕ_И_КАЧЕСТВО/` — тестовые стратегии, воспроизводимые проверки, регрессии и quality gates;
- `ИНФРАСТРУКТУРА_И_РАЗВЁРТЫВАНИЕ/` — окружения, сборка, CI/CD, релизы, наблюдаемость и восстановление;
- `РАБОТА_С_ИИ_И_АВТОМАТИЗАЦИЕЙ/` — работа с моделями, агентами, инструментами и автоматизированными процессами.

## Обязательные условия

1. Используй `SKILL_TEMPLATE.md`.
2. Проверь один из двух путей Outcome Gate.
3. Для новой записи оставь безопасные стартовые статусы: `CANDIDATE`, `DRAFT`, `reviewed: false`, если нет отдельного подтверждённого решения.
4. Не устанавливай `maturity: VALIDATED` только потому, что Outcome Gate пройден.
5. Перед размещением проведи Sorter DRY RUN и дождись решения пользователя.
6. После ручного одобрения, размещения и проверки обнови `ИНДЕКС_ЗНАНИЙ.md`.

Если подходящей категории нет, не создавай её автоматически. Предложи владельцу добавить тематическую папку и обновить этот README.
