# Архив базы знаний

Здесь хранятся записи SKILL, EXPERIENCE и INSIGHT, которые владелец явно решил физически вывести из активных каталогов, но сохранить для истории, аудита или ссылочной целостности.

Архивирование не выполняется автоматически при `priority: COLD`, `maturity: DEPRECATED` или `maturity: SUPERSEDED`. Это отдельное решение владельца.

Перед перемещением проверь ссылки, зависимости, наличие заменяющей записи, уникальность домена, HOT-связи, индекс и Git-историю. Сохраняй исходный ID и содержимое. Не переписывай архивную запись ради соответствия текущим шаблонам без отдельной миграции и решения владельца.

Подкаталоги сохраняют тип записи: `НАВЫКИ/`, `ПРАКТИЧЕСКИЙ_ОПЫТ/`, `ИНСАЙТЫ/`. При необходимости сохраняй внутри них исходную тематическую структуру. Архивные записи не подаются Router/Worker как текущие инструкции без явной проверки их применимости.
