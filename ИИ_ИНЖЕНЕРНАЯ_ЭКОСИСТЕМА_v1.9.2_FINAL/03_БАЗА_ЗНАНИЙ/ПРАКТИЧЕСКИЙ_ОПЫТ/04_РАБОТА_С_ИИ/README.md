Практические случаи взаимодействия с ИИ-моделями, агентами, промптами, контекстом и межчатовой передачей.

Размещай здесь принятые записи `EXPERIENCE` по шаблону `../ШАБЛОНЫ/EXPERIENCE_TEMPLATE.md`. Классифицируй эпизод по основной теме, а дополнительные области отражай в YAML `tags`. Не копируй одну запись в несколько папок. Новые материалы до решения владельца остаются в `04_INBOX/НОВЫЕ/`.
