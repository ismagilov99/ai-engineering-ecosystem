# ОТКЛОНЕНО — материалы, не принятые владельцем

Здесь хранятся материалы, которые пользователь явно отказался включать в активную БЗ, но решил сохранить для истории, сравнения или аудита.

## Правила хранения

- Перемещение сюда выполняет только пользователь после явного решения.
- Отклонение не происходит автоматически из карантина или из-за низкой оценки Sorter.
- Валидный файл может иметь `status: REJECTED`, если владелец вручную зафиксировал это решение в YAML. Не исправляй исходник автоматически.
- Не включай такие материалы в `ИНДЕКС_ЗНАНИЙ.md`, активные счётчики и обычные рекомендации Router/Worker.
- Сохраняй объяснение причины отказа, если это не раскрывает секреты и полезно для предотвращения повторной работы.
- Не удаляй материалы автоматически. Срок хранения, архивация или удаление определяются владельцем.

Если позднее появляется новое evidence или меняются условия, пользователь может поручить повторное рассмотрение. Не возвращай запись в активную БЗ автоматически: она проходит актуальную проверку и новый цикл одобрения.
